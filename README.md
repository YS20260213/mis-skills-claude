# Mis skills de Claude Code

Skills guardados para usarlos siempre en Claude Code.

## Incluye
- **anatomy** — figuras SVG isométricas interactivas y detalladas (con WebGL opcional y exportación a PDF A4). Ver `.claude/skills/anatomy/SKILL.md`.

## Cómo usarlo
- **En Claude Code en la web/app:** inicia una sesión con este repositorio seleccionado; el skill se carga solo desde `.claude/skills/`.
- **En tu computadora:** copia la carpeta a tus skills personales:
  ```bash
  cp -r .claude/skills/anatomy ~/.claude/skills/
  ```

Luego pide algo como: "haz un isométrico de una cafetera explicando cómo funciona".
